# Arc Tanks

An original, dependency-free turn-based artillery game inspired by classic trajectory battlers.

## Features
- Destructible terrain and crater deformation
- Wind, angle and power ballistics
- Smart AI with three difficulty levels
- Local 2-player pass-and-play
- 8 weapons with distinct behaviors
- Health, damage falloff, knockback, particles, screen shake and sound
- Responsive desktop/mobile controls
- Installable PWA support
- No external libraries or assets

## Run locally
Use any static web server. For example:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Controls
Desktop: Left/Right = angle, Up/Down = power, A/D = weapon, Space = fire.
Mobile: on-screen controls.
