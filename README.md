# Arc Tanks V2

Arc Tanks is an original browser artillery game with destructible terrain, turn-based ballistic combat, local multiplayer, and AI opponents.

## V2 highlights
- Pre-match shared projectile draft with alternating picks
- Quick Pack option for instant randomized loadouts
- 24 distinct projectiles across Standard, Explosive, Terrain, Energy, and Chaos classes
- Dedicated projectile sprite sheet plus animated in-flight projectile rendering and trails
- Weapon drawer during battle for direct projectile selection
- Special weapon behaviors including split shots, ricochets, rollers, drilling, terrain building, gravity pulls, napalm, lightning, airstrikes, meteor calls, beams, and more
- 8 terrain generators: Rolling Hills, Twin Peaks, Canyon, Bowl, Jagged Badlands, Flatlands, Asymmetric, and Broken Islands
- Randomized battlefield color themes and improved effects, tank recoil, muzzle flash, damage text, debris, screen shake, beams, and hazards
- Responsive desktop/mobile controls and PWA support

## Controls
Desktop: Left/Right = angle, Up/Down = power, W = arsenal, A/D = cycle projectile, Space = fire.

Mobile: use the on-screen controls and Arsenal button.

## Local run
```bash
python -m http.server 8080
```
Then open `http://localhost:8080`.
